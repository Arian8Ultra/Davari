# Introduction

This is Davari project for mporg and it uses React v18.2.0 and Typescripts as base and it usese vite development

1. @apollo/client: for graphql client
2. @emotion/react: for styling

4. @mui/icons-material: for icons
5. @mui/joy: for base components
6. @mui/lab: for components
7. @mui/material: for most components
8. @mui/x-date-pickers: for date pickers
9. @types/jest: for testing
10. @types/node: for node types
11. @types/react-router-dom: for react router dom types
12. date-fns-jalali: for jalali date

14. framer-motion: for animation

17. react
